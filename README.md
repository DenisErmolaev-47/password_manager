# Password Manager

Консольный менеджер паролей с шифрованием данных, защитой мастер-паролем и генератором случайных комбинаций.

## Безопасность и технологии
- **Шифрование:** Используется симметричный алгоритм `Fernet` из библиотеки `cryptography`.
- **Защита мастер-пароля:** Генерация ключа с помощью `PBKDF2HMAC` (SHA-256) с использованием случайной соли (`salt.bin`).
- **Тестирование:** Покрытие тестами с помощью фреймворка `pytest`.
